A lightweight tag suggestion plugin for FlatBB.

## Features

- Reads existing tags from the `fb_tags` table.
- Shows up to five related suggestions.
- Inserts the selected tag into the original FlatBB tags field.
- Separates tags with commas.
- Supports Persian and English typing.
- Supports mouse selection.
- Supports ArrowUp and ArrowDown.
- Supports Enter selection.
- Keeps the suggestion list open after selecting a tag.
- Supports Escape to close the list.
- No external JavaScript dependencies.
- No extra database tables.
- No additional settings required.

## Requirements

- FlatBB 0.1.50 or newer.
- The standard FlatBB `fb_tags` table.

## Installation

Upload the ZIP through the FlatBB plugin manager and activate `Tag Autocomplete`.
